Módulo central que contiene todos los entregables finales del sistema hospitalario, incluyendo aplicaciones, documentación técnica, builds y manuales de usuario.

---

## 📝 Descripción General

La carpeta `Deliverables` centraliza los componentes finales desarrollados durante el proyecto, permitiendo organizar las versiones listas para implementación, pruebas y distribución. 

Este módulo reúne los sistemas principales, documentación técnica y recursos necesarios para el despliegue y utilización del entorno hospitalario, proporcionando un conjunto organizado de aplicaciones y servicios listos para su uso.
