Aplicación web principal del Sistema Hospitalario UDN-RH, diseñada para la administración, monitoreo y gestión integral de la información hospitalaria.

---

## 📝 Descripción General

La **WebApp** constituye la plataforma principal de interacción para médicos, personal administrativo y usuarios autorizados del sistema hospitalario.

Su objetivo es proporcionar una interfaz moderna, intuitiva y accesible que permita gestionar información crítica de manera eficiente, facilitando la operación diaria de la institución.

La aplicación se comunica con la API del sistema para consultar, registrar y actualizar información en tiempo real, garantizando una experiencia segura y confiable.

---

## 🚀 Funcionalidades Principales

### 👤 Gestión de Usuarios

* Registro de usuarios
* Inicio y cierre de sesión
* Administración de roles y permisos
* Recuperación de credenciales

### 🏥 Administración Hospitalaria

* Gestión de pacientes
* Administración de personal médico
* Control de áreas y departamentos
* Seguimiento de actividades hospitalarias

### 📋 Consulta de Información Médica

* Visualización de expedientes
* Consulta de historiales clínicos
* Acceso a registros médicos autorizados
* Seguimiento de tratamientos

### 📊 Reportes y Estadísticas

* Generación de reportes
* Visualización de indicadores
* Estadísticas operativas
* Exportación de información

### 📡 Monitoreo en Tiempo Real

* Seguimiento de eventos
* Actualización dinámica de información
* Notificaciones automáticas
* Integración con servicios hospitalarios
