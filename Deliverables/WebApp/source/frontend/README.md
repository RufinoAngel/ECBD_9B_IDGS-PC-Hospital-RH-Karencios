# 🌐 Frontend - WebApp

![Frontend](https://img.shields.io/badge/Frontend-React-blue?style=for-the-badge)
![Estado](https://img.shields.io/badge/UI-Web-success?style=for-the-badge)

Interfaz principal de la aplicación web del sistema hospitalario.

---

## 📝 Descripción General

Permite a médicos, administradores y personal autorizado interactuar con la plataforma mediante una interfaz moderna y responsiva.

---

## 🚀 Funcionalidades

* Gestión de pacientes
* Administración de usuarios
* Consulta de historiales
* Visualización de reportes
* Paneles administrativos

---

## 🛠 Tecnologías Utilizadas

* React
* JavaScript
* HTML5
* CSS3
* Tailwind CSS

---

## 📂 Componentes

* Pages
* Components
* Services
* Assets
* Hooks

---

## 🎯 Objetivo General

Facilitar la administración y consulta de información hospitalaria mediante una experiencia web intuitiva.
