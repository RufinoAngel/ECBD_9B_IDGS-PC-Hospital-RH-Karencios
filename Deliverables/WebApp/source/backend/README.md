# 🖥️ Backend - WebApp

![Backend](https://img.shields.io/badge/Backend-Node.js-green?style=for-the-badge)
![API](https://img.shields.io/badge/Servicios-REST-blue?style=for-the-badge)

Backend encargado de administrar la lógica de negocio de la aplicación web hospitalaria.

---

## 📝 Descripción General

Gestiona la comunicación entre la interfaz web y las bases de datos, procesando solicitudes, validando información y garantizando la seguridad de los datos.

---

## 🚀 Funcionalidades

* Gestión de usuarios
* Administración hospitalaria
* Validación de datos
* Comunicación con bases de datos
* Seguridad y autenticación

---

## 🛠 Tecnologías Utilizadas

* Node.js
* Express.js
* JWT
* MySQL
* MongoDB

---

## 🎯 Objetivo General

Proporcionar servicios backend robustos y escalables para la plataforma web hospitalaria.
