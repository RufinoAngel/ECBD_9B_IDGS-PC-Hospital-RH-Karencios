Versión compilada y optimizada de la aplicación web del Sistema Hospitalario UDN-RH, preparada para su implementación en entornos de producción.

---

## 📝 Descripción General

La carpeta `build` contiene todos los archivos generados automáticamente durante el proceso de compilación de la aplicación web.

Estos recursos han sido optimizados para mejorar el rendimiento, reducir los tiempos de carga y garantizar una experiencia de usuario eficiente en ambientes productivos.

El contenido de esta carpeta representa la versión final de la aplicación lista para ser desplegada en servidores web o servicios de alojamiento.

---

## 📂 Contenido del Entregable

### 🌐 Archivos Estáticos

* Páginas HTML optimizadas
* Estructura principal de la aplicación
* Recursos de navegación

### 🎨 Hojas de Estilo

* Archivos CSS minificados
* Estilos optimizados para producción
* Diseño responsive

### ⚙️ Scripts JavaScript

* Código compilado y optimizado
* Componentes empaquetados
* Gestión de eventos y funcionalidades

### 🖼️ Recursos Multimedia

* Imágenes optimizadas
* Iconos
* Logos institucionales
* Recursos gráficos

---

## 🚀 Características

## 📋 Uso del Build

La carpeta puede ser utilizada para:

* Despliegue en servidores web
* Publicación en servicios cloud
* Pruebas de producción
* Distribución de versiones estables

---

## 🎯 Objetivo General

Proporcionar una versión compilada, optimizada y lista para producción de la aplicación web hospitalaria, garantizando estabilidad, rendimiento y facilidad de despliegue.
