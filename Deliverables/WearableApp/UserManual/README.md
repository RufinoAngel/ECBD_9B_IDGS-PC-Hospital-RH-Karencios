Manual de usuario de la aplicación wearable del Sistema Hospitalario UDN-RH.

---

## 📝 Descripción General

La carpeta `UserManual` contiene la documentación orientada a los usuarios finales de la aplicación wearable.

Su propósito es proporcionar instrucciones claras y detalladas para el uso correcto de la plataforma, permitiendo aprovechar todas sus funcionalidades de monitoreo, consulta de información y gestión de alertas.

Este manual está diseñado para facilitar la adopción del sistema por parte del personal hospitalario, reduciendo tiempos de aprendizaje y mejorando la experiencia de uso.
