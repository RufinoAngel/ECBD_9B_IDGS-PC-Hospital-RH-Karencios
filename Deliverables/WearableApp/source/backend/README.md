# ⚙️ Backend - WearableApp

![Backend](https://img.shields.io/badge/Backend-Node.js-green?style=for-the-badge)
![Estado](https://img.shields.io/badge/Estado-En%20Desarrollo-blue?style=for-the-badge)

Backend encargado de gestionar la lógica de negocio, procesamiento de datos y comunicación entre la aplicación wearable y los servicios del sistema hospitalario.

---

## 📝 Descripción General

Este módulo recibe, procesa y distribuye la información generada por la aplicación wearable.

Permite la conexión con bases de datos, APIs externas y sistemas de monitoreo, garantizando la disponibilidad de la información en tiempo real.

---

## 🚀 Funcionalidades

* Procesamiento de solicitudes HTTP
* Gestión de usuarios y sesiones
* Comunicación con bases de datos
* Validación de información
* Gestión de alertas y eventos
* Integración con APIs REST

---

## 🛠 Tecnologías Utilizadas

* Node.js
* Express.js
* MongoDB
* MySQL
* JWT

---

## 📂 Componentes

* Controllers
* Routes
* Middleware
* Services
* Models
* Config

---

## 🎯 Objetivo General

Gestionar de manera segura y eficiente toda la lógica operativa de la aplicación wearable.
