# 🎨 Frontend - WearableApp

![Frontend](https://img.shields.io/badge/Frontend-React-blue?style=for-the-badge)
![UI](https://img.shields.io/badge/Interfaz-Usuario-purple?style=for-the-badge)

Interfaz gráfica encargada de mostrar la información procesada por el sistema wearable.

---

## 📝 Descripción General

Este módulo proporciona una experiencia visual intuitiva para el monitoreo de información hospitalaria en tiempo real.

Permite visualizar métricas, alertas, notificaciones y datos relevantes provenientes de la API.

---

## 🚀 Funcionalidades

* Visualización de métricas
* Monitoreo en tiempo real
* Gestión de alertas
* Navegación entre módulos
* Consumo de APIs REST

---

## 🛠 Tecnologías Utilizadas

* React
* JavaScript
* HTML5
* CSS3

---

## 📂 Componentes

* Components
* Pages
* Hooks
* Services
* Assets
* Styles

---

## 🎯 Objetivo General

Brindar una interfaz moderna, accesible y eficiente para la interacción con el sistema wearable.
