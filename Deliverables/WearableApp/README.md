Aplicación wearable desarrollada para el monitoreo, visualización y consulta de información hospitalaria en tiempo real mediante dispositivos inteligentes.

---

## 📝 Descripción General

La **WearableApp** forma parte del ecosistema tecnológico del Sistema Hospitalario UDN-RH y está diseñada para proporcionar acceso rápido y portátil a información médica relevante.

La aplicación permite visualizar métricas, recibir alertas y consultar datos críticos desde dispositivos inteligentes, facilitando la movilidad y la capacidad de respuesta del personal médico y administrativo.

Su integración con los servicios backend garantiza la sincronización de información en tiempo real y una experiencia de uso eficiente dentro del entorno hospitalario.
