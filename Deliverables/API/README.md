# 🔌 Hospital API

![Backend](https://img.shields.io/badge/Backend-Node.js-green?style=for-the-badge)
![Arquitectura](https://img.shields.io/badge/API-REST-blue?style=for-the-badge)

Servicio API REST encargado de la comunicación entre las aplicaciones del ecosistema hospitalario.

---

## 📝 Descripción General

La API constituye el núcleo de procesamiento del sistema. Gestiona solicitudes provenientes de la WebApp y WearableApp, realiza validaciones, ejecuta reglas de negocio y administra la comunicación con las bases de datos.

---

## 📂 Estructura

```text
API
│
├── build
├── DeployManual
└── source
```

---

## ⚙️ Funcionalidades

* Gestión de usuarios
* Autenticación y autorización
* Administración hospitalaria
* Gestión de historiales clínicos
* Integración con bases de datos
* Servicios REST

---

## 🛠 Tecnologías

* Node.js
* Express.js
* JWT
* MySQL
* MongoDB

---

## 🎯 Objetivo General

Proporcionar una capa de servicios segura y escalable para la gestión de información hospitalaria.
