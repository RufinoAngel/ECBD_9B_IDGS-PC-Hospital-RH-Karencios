# 🏥 Hospital RH - Recursos Humanos

Proyecto integral de análisis y modelado de datos para la gestión de Recursos Humanos en instituciones hospitalarias 
## 📋 Descripción del Proyecto

Este proyecto desarrolla modelos de aprendizaje automático para optimizar la gestión de Recursos Humanos en hospitales, permitiendo:

- Análisis predictivo del desempeño del personal
- Segmentación de empleados mediante clustering
- Optimización de procesos de selección y retención
- Identificación de patrones en datos de RH
- Toma de decisiones basada en datos
